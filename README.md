# time-landing

`Gertu` цаг бүртгэлийн системийн **танилцуулга (landing) сайт**. Нэг хуудас,
монгол хэлээр, 14 хоногийн үнэгүй туршилт руу чиглүүлсэн.

Технологи нь `time-admin`-тай ижил: Vite + React 19 + TypeScript + Tailwind v4.
Өнгө (`--brand: #5b5bd6`) нь админ веб-тэйгээ тааруулсан тул хэрэглэгч
сайтаас систем рүү шилжихэд өнгө тасрахгүй.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview
```

## Юуг заавал солих вэ

Доорх зүйлс нь ЗАГВАР утгатай байгаа — нийтлэхээсээ өмнө солино:

| Хаана | Юу | Одоо |
|---|---|---|
| `src/lib/lead.ts` | `LEAD_ENDPOINT` | **хоосон** — маягт хаашаа ч илгээхгүй |
| `src/content.ts` → `BRAND` | утас, имэйл, хаяг, `appUrl` | `7000-0000`, `info@gertu.mn` |
| `src/content.ts` → `PRICING` | багцын үнэ | `₮3,900` / `₮5,900` |
| `src/components/apps.tsx` | App Store / Google Play холбоос | `#signup` руу чиглэсэн |

> ⚠️ `LEAD_ENDPOINT` хоосон байхад маягт хэрэглэгчид «Хүсэлт хүлээн авлаа»
> гэж хэлэх атлаа өгөгдөл хаашаа ч очихгүй. Хөгжүүлэлтийн горимд маягт дээр
> шар анхааруулга гарна; нийтлэхээсээ өмнө хаягаа тавина уу.

## Бүтэц

```
src/
  content.ts          ← БҮХ бичвэр, үнэ, асуулт хариулт энд
  lib/lead.ts         ← бүртгүүлэх хүсэлтийг хүлээн авах цэг
  components/
    nav, hero, feature-tabs, modules, apps,
    steps, pricing, faq, signup, footer
    mock-dashboard.tsx / mock-phone.tsx  ← системийн дүрслэл
    ui.tsx            ← Section, Button, Reveal гэх мэт
```

Маркетингийн үг өөрчлөхөд `src/content.ts` л хангалттай — компонент ухах
шаардлагагүй.

## Дүрслэл (mock) талаар

`mock-dashboard.tsx`, `mock-phone.tsx` нь **жинхэнэ дэлгэцийн зураг биш**,
бодит дэлгэцийн бүтцийг давтсан HTML/CSS загвар. Ингэснээр:

- хэрэглэгчийн жинхэнэ нэр, тоо задрахгүй
- систем шинэчлэгдэх бүрд зураг дарж солих шаардлагагүй
- утсан дээр ч тод харагдана (растер зураг бүдгэрдэг)

Доторх нэр, тоо (`Б. Мишээл`, `42 ирсэн`) нь **үзүүлэнгийн** утга.

## Тоон үзүүлэлт

`STATS` дотор «1300 байгууллага» гэх мэт хэрэглэгчийн тоо ЗОРИУД байхгүй —
батлагдаагүй тоо бичихээс зайлсхийсэн. Оронд нь системд үнэхээр байгаа
боломжийг тоолсон (20+ модуль, 6 бүртгэх арга гэх мэт). Жинхэнэ тоогоо
нийтлэхэд бэлэн болоод солиорой.
